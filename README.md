# GitHub Issues Tracker

A lightweight web application designed to track and manage project issues effectively. This project fetches real-time data from a remote API and provides a clean, responsive interface for organizing tasks.

---

### **Repository Overview (Description)**
**GitHub Issues Tracker** – A dynamic issue management tool built with vanilla JavaScript and modern CSS frameworks.
* **Live Link:** 
**Tech Stack:** JavaScript, Tailwind CSS, DaisyUI, REST API.

---

### **Main Features**
***Authentication System:** Secure access using a demo login system for managing issues.
***Real-time Search:** Instantly find specific issues using the integrated search bar.
***Status Filtering:** Organize your view by filtering issues into 'All', 'Open', or 'Closed' categories.
***Detailed Issue Modals:** Click on any card to view comprehensive details, including descriptions, authors, and creation dates.
***Visual Indicators:** Color-coded badges for priorities (High, Medium, Low) and custom labels for bug tracking and enhancements.

---

### **Technology Stack**
***Frontend:** HTML5 and JavaScript (ES6+).
***Styling:** Tailwind CSS for layout and DaisyUI for specialized components.
***Icons & Fonts:** Font Awesome icons and the Geist font family.
***Data Handling:** Fetch API for asynchronous communication with the Phi Lab Server.

---

### **Dependencies**
This project leverages external libraries via CDN for easy setup:
***Tailwind CSS v4:** Utility-first CSS framework.
***DaisyUI v5:** Component library for Tailwind CSS.
***Font Awesome 7.0.1:** Icon library.
